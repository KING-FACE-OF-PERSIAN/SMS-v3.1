# Consent SMS — نسخه ۱.۳ رنگی + بازه شماره + اتصال مطمئن به برنامه SMS

این پروژه یک اپ اندروید با ظاهر نزدیک به طرح گرافیکی قبلی است و برای **آماده‌سازی، پیش‌نمایش، صف‌بندی و زمان‌بندی امن پیامک** ساخته شده است.

## قابلیت‌ها
- رابط گرافیکی تیره و رنگی با گرادیان بنفش، صورتی، آبی و فیروزه‌ای
- ورود چند شماره موبایل ایران (`09`, `+98`, `0098`)
- حالت «بازه شماره» از شماره شروع تا شماره پایان، همراه با شمارش زنده
- پشتیبانی از حداکثر ۵۰۰ گیرنده در هر صف (نمونه `09352000123` تا `09352000567` شامل ۴۴۵ شماره)
- الزام تأیید رضایت گیرندگان هنگام استفاده از بازه شماره
- متن دلخواه
- تعیین تعداد تکرار در حالت فهرست دستی؛ در حالت بازه هر شماره یک بار آماده می‌شود
- پیش‌نمایش پیام
- پنل گزارش با آمار `ارسال شده / باقی‌مانده / ناموفق`
- ثبت دستی نتیجه هر تلاش بعد از بازگشت از برنامه SMS
- توقف و ادامه صف ارسال
- تشخیص بازگشت از برنامه پیامک و نمایش مرحله بعد
- راهنمای واضح برای انتخاب سیم‌کارت ۱ یا ۲ در برنامه SMS گوشی
- منوی همبرگری فعال با راهنما، تنظیمات شبکه و درباره برنامه
- منوی پایین جمع‌وجور با رعایت فاصله از نوار سیستم اندروید
- تشخیص برنامه پیش‌فرض SMS و نمایش وضعیت آماده‌بودن آن
- هدف‌گیری مستقیم برنامه پیش‌فرض SMS برای بازکردن مطمئن شماره و متن
- میانبر انتخاب برنامه پیش‌فرض SMS در تنظیمات اندروید
- زمان‌بندی برای تاریخ و ساعت خاص
- یادآوری در زمان مقرر و بازکردن پیام آماده با تأیید کاربر
- پروژه آماده GitHub Actions برای ساخت APK

## محدودیت ایمنی
این پروژه **ارسال خودکار/پنهان/انبوه بدون تأیید کاربر** را انجام نمی‌دهد.

در حالت بازه، شماره‌ها تولید و در صف قرار می‌گیرند؛ اما هر پیام همچنان با باز شدن برنامه SMS و تأیید کاربر ارسال می‌شود. ارسال مستقیم، مخفی یا بدون رضایت انجام نمی‌شود.

در گوشی دو سیم‌کارته، انتخاب سیم‌کارت توسط برنامه SMS پیش‌فرض گوشی انجام می‌شود. پس از ارسال، به Consent SMS برگرد و نتیجه را دستی ثبت کن.

این روش از Intent استاندارد `ACTION_SENDTO` با طرح `smsto:` استفاده می‌کند و به مجوز حساس `SEND_SMS` یا دسترسی مستقیم سیم‌کارت نیاز ندارد.

## استفاده از حالت بازه
1. در صفحه «ارسال سریع»، گزینه «بازه شماره» را انتخاب کن.
2. شماره شروع و پایان را وارد کن؛ تعداد گیرندگان همان لحظه نمایش داده می‌شود.
3. تأیید رضایت گیرندگان را فعال و متن پیام را وارد کن.
4. روی «شروع / پیش‌نمایش» بزن و تعداد گیرندگان و متن را بررسی کن.
5. شروع صف را تأیید کن. برای هر گیرنده، برنامه SMS گوشی باز می‌شود.
6. نتیجه هر تلاش را ثبت کن؛ با «توقف صف» می‌توان ادامه عملیات را موقتاً متوقف کرد.

## ساخت APK با GitHub
1. همه فایل‌ها را در GitHub آپلود کن.
2. به تب `Actions` برو.
3. Workflow با نام `Build Android APK` را اجرا کن.
4. بعد از اتمام، از بخش `Artifacts` فایل `ConsentSMS-debug-apk` را دانلود کن.
5. ZIP را Extract کن و `app-debug.apk` را نصب کن.
